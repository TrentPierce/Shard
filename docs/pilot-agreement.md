## What We Provide

### Free Setup
- Complete private Shard network setup (10-minute process)
- One-click deployment via our setup script
- Configuration tailored to your organization

### Technical Support
- Email support during pilot period
- Slack channel for real-time help
- Setup documentation and FAQ

### Monitoring
- Access to pilot dashboard showing:
  - Active compute contributors
  - Requests served
  - Estimated cost savings vs. traditional API

### Security
- Private mesh option (traffic stays within your network)
- Localhost-first routing
- No data leaves your infrastructure by default

### Infrastructure
- One server (physical or VM) to run the verifier node
- Minimum: 4GB RAM, 2 CPU cores
- Recommended: 8GB RAM, 4+ CPU cores for better performance

### Participation
- At least 10 team members contributing browser compute
- A single point of contact for coordination

### Feedback
- One 30-minute feedback call at the end of the pilot
- Brief survey about your experience (5 minutes)
